# Security policy

This is a pre-1.0 engineering project, not an independently audited security product.
Only the latest tagged release is intended to receive fixes.

Please report vulnerabilities privately using GitHub private vulnerability reporting
on this repository once the maintainer enables it. Do not post credentials or
sensitive exploit details in public issues. If that feature is unavailable, contact
the maintainer through a verified contact listed on their GitHub profile.

Include affected version, prerequisites, reproduction steps and impact. Use only
local fixtures or systems you are authorized to test. See docs/THREAT-MODEL.md for
trust assumptions and known limits.
