# Changelog

## 0.1.0

Initial implementation: Go tools gateway, fixed-issuer RS256 token validation,
PostgreSQL authorization/audit/one-use approvals, Redis limits, per-user downstream
credentials, demo backend, Keycloak realm, PKCE login helper, Compose observability,
Kubernetes template, security-boundary tests and GitHub Actions workflows.

Compatibility is intentionally scoped to MCP 2025-11-25 JSON/stateless tools.
